# サントラベル 公式サイト（リニューアル版）

韓国専門旅行社・株式会社サントラベル（観光庁長官登録旅行業 第1791号）の公式サイトです。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | 企業トップページ（事業内容・会社案内・沿革・アクセス・お問い合わせ） |
| `tours.html` | ツアー予約サイト（検索・エリア・カテゴリ・ランキング・ツアー一覧・空席カレンダー・予約画面） |
| `visa.html` | ビザ申請代行（韓国・米国ビザ、e-Arrival Card） |
| `img/` | 写真（Web用に圧縮済み） |
| `docs/企画書.md` | サイトの企画書・要件 |
| `sheet/サントラベル予約管理.xlsx` | 予約管理スプレッドシートのひな形（Googleスプレッドシートに変換して使用） |
| `gas/Code.gs`・`gas/appsscript.json` | スプレッドシートとサイト・Googleカレンダーをつなぐ Apps Script |

外部ライブラリは使っていません。フォントは Google Fonts から読み込みます。

## ローカルで確認する

`index.html` をブラウザで開くだけで表示できます。

## 公開する（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
4. 独自ドメイン（例：suntravel.jp）は同じ画面の **Custom domain** で設定します

※ 非公開（private）リポジトリで GitHub Pages を使うには、GitHub の有料プランが必要です。無料で公開したい場合は、Netlify や Cloudflare Pages にこのリポジトリを連携する方法もあります。

## 予約管理スプレッドシートとの連携

ツアー・出発日・料金・残席を Google スプレッドシートで管理し、サイトの表示と空席カレンダーに反映します。サイトからの予約はシートの「予約」に自動で追加され、出発日ごとの予約状況は Google カレンダーに同期されます。

```
サイト（Cloudflare Pages）
  ├─ GET  ?action=tours → ツアー・受付中の出発日・残席を取得（空席カレンダー）
  └─ POST action=book   → 予約を登録（料金・残席はサーバー側で再計算）
        ↓
Apps Script（スプレッドシートにひも付け）
  ├─ ツアー／出発日／予約／同行者／ダッシュボード の各シート
  └─ Google カレンダー（出発日ごとの終日予定：予約人数・残席・予約者一覧）
```

### 設定手順（最初に1回）

1. スプレッドシート「サントラベル予約管理」を開き、**拡張機能 → Apps Script** を開く
2. `gas/Code.gs` の内容を貼り付ける。歯車（プロジェクトの設定）で「appsscript.json をエディタで表示」をオンにし、`gas/appsscript.json` の内容に置き換えて保存
3. 必要なら `CONFIG` の `STAFF_EMAIL`（新規予約の通知先）と `CALENDAR_ID`（同期先カレンダー）を設定
4. **デプロイ → 新しいデプロイ → 種類：ウェブアプリ**。実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイし、権限を承認
5. 表示されたウェブアプリの URL を `tours.html` の `var API_URL='';` に入れてコミット
6. スプレッドシートを開き直し、メニュー **サントラベル → カレンダーに同期**、続けて **毎時の自動同期をオンにする**

`API_URL` が空のときは、サイトは掲載中の見本データでデモとして動きます。

## 現状の注意点

- **カード決済はまだ連携していません。** スプレッドシート連携後も、予約は「仮予約」として登録されます。 実際の決済には、決済代行会社（Stripe、GMOペイメントゲートウェイなど）との契約と、予約・在庫を管理するサーバー側の仕組みが必要です。
- 掲載の日程・料金・評価・体験談は**見本**です。公開前に実際の内容へ差し替えてください（架空の口コミの掲載は景品表示法上の問題になります）。
- 人物写真の一部は生成画像です。「当社スタッフ」として掲載する場合は実際の写真に差し替えてください。
