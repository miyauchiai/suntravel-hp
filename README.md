# サントラベル 公式サイト（リニューアル版）

韓国専門旅行社・株式会社サントラベル（観光庁長官登録旅行業 第1791号）の公式サイトです。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | トップページ（検索・エリア・カテゴリ・ランキング・ツアー一覧・予約画面） |
| `img/` | 写真（Web用に圧縮済み） |
| `docs/企画書.md` | サイトの企画書・要件 |

外部ライブラリは使っていません。フォントは Google Fonts から読み込みます。

## ローカルで確認する

`index.html` をブラウザで開くだけで表示できます。

## 公開する（GitHub Pages）

1. リポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にして保存
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
4. 独自ドメイン（例：suntravel.jp）は同じ画面の **Custom domain** で設定します

※ 非公開（private）リポジトリで GitHub Pages を使うには、GitHub の有料プランが必要です。無料で公開したい場合は、Netlify や Cloudflare Pages にこのリポジトリを連携する方法もあります。

## 現状の注意点

- **予約・決済はデモです。** 実際の決済には、決済代行会社（Stripe、GMOペイメントゲートウェイなど）との契約と、予約・在庫を管理するサーバー側の仕組みが必要です。
- 掲載の日程・料金・評価・体験談は**見本**です。公開前に実際の内容へ差し替えてください（架空の口コミの掲載は景品表示法上の問題になります）。
- 人物写真の一部は生成画像です。「当社スタッフ」として掲載する場合は実際の写真に差し替えてください。
