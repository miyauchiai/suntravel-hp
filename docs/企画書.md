# 株式会社サントラベル 公式HP リニューアル企画書（v0.7）

更新日：2026-11-13　現行サイト：https://suntravel.jp

## 1. 会社の位置づけ
- 韓国専門旅行社（1996年創業、第1種旅行業 観光庁長官登録旅行業 第1791号）
- 本社：新横浜 ／ 東京本店営業所：新大久保（百人町）
- 強み：格安航空券、K-POP観覧ツアー、地方の祭り・美食・美容などのテーマ旅行、現地発ツアー、ビザ申請代行（韓国 C-3-9 / C-4-5 / C-3-4、米国 B-1 / B-2、e-Arrival Card）

## 2. デザイン方針（v0.5）
- 予約サイト型（参考：VELTRA の構成。ロゴ・配色は流用しない）
- 構成：検索（行き先・日付・キーワード）→ エリア → カテゴリ → 人気ランキング → 特集 → ツアー一覧（絞り込み・並び替え）→ 体験談 → 航空券・ビザ・団体 → 電話相談 → お知らせ・登録情報
- 白地＋青磁グリーンのブランド色、価格は朱色。ハングルをアクセントに使用
- 提供写真12点を使用。生成画像の人物写真は「当社スタッフ」と表記しない（実写に差し替え推奨）
- 評価・体験談は見本。公開時は実際の参加者の評価に差し替える（架空の口コミは景品表示法上の問題）

## 3. サイトマップ（v0.7〜 3ページ構成）
1. **企業トップ（index.html）**：事業内容、受託販売、強み、お知らせ、会社案内・沿革・旅行業登録、アクセス、お問い合わせ
2. **ツアー予約サイト（tours.html）**：検索、エリア、カテゴリ、ランキング、特集、ツアー一覧、空席カレンダー、オンライン予約
3. **ビザ申請代行（visa.html）**：ビザが必要な方、受付対象、取扱いビザ、料金、必要書類、申請の流れ、よくある質問、窓口
4. 今後：ツアー詳細、ご予約明細、規約（旅行条件書・旅行業約款・特定商取引法に基づく表記・個人情報）

## 4. オンライン予約・決済
### 予約の流れ（デモ実装済み）
1. 日程・人数：出発日ごとの残席表示、大人／子供、部屋タイプ、出発空港
2. お客様情報：代表者（漢字・ローマ字・生年月日・連絡先・旅券有効期限）、同行者（ローマ字・生年月日）
3. 旅行条件：含まれるもの／含まれないもの、最少催行人員、取消料表、同意チェック3点
4. お支払い：全額 or 申込金（出発21日前より前のみ）、クレジットカード or 銀行振込
5. 予約完了：予約番号、契約書面のメール送付、残金期限、出発前の案内

### 法令・約款上の要件
- 取引条件説明書面（旅行条件書）を申込み前に提示し、同意を得る（旅行業法 第12条の4）
- 書面を電磁的方法で交付する場合は、お客様の承諾を得る
- 契約成立後、遅滞なく契約書面を交付（同 第12条の5）→ 予約確定メールで送付
- カード決済は「通信契約」（標準旅行業約款）：承諾通知の到達で契約成立
- 取消料は標準旅行業約款 別表どおりに表示（ピーク時40〜31日前10%を含む）。現地発ツアーの取消料は要確認

### 決済まわりの要件
- カード情報は自社で保持しない（決済代行会社のトークン決済。割賦販売法のカード情報非保持化）
- EMV 3-Dセキュア（本人認証）必須
- 銀行振込は期限管理と入金消込、期限切れ時の自動キャンセル
- 申込金・残金の二段階決済（残金は出発21日前まで）

### 実装時に決めること
- 決済代行会社の選定（Stripe、GMOペイメントゲートウェイ、ペイジェントなど）
- 現行サイトの「マイアカウント／予約手続き」を使い続けるか、新しい予約システムに移行するか
- 在庫（座席・客室）の管理元：手入力か、航空会社・ホテルの仕入れ枠と連携するか
- 予約確定後の社内フロー（担当者通知、手配、eチケット発行）

## 5. 公開環境（v0.5で追加）
- ソースは GitHub リポジトリで管理（index.html ＋ img/ ＋ docs/）
- 公開先の候補：GitHub Pages（private リポジトリは有料プラン）、Netlify、Cloudflare Pages
- 独自ドメイン suntravel.jp への切り替えは、DNS 設定の変更で行う（現行サイトからの移行時期を要調整）
- 予約・決済を本番化する段階では、サーバー側の仕組み（API・データベース）が別途必要
- バックアップ：Google ドライブ「サントラベルHP バックアップ」フォルダ

## 6. 予約管理スプレッドシート・カレンダー連携（v0.6で追加）
- Googleスプレッドシート「サントラベル予約管理」（ドライブ「サントラベル 予約管理」フォルダ）
- シート：ツアー（プラン内容・料金・公開）／出発日（定員・受付、予約人数・残席・催行状況は自動計算）／予約（サイトから自動追加、入金額を入れると入金状況・未収・期限超過を自動判定）／同行者／ダッシュボード
- Apps Script（gas/Code.gs）をウェブアプリとして公開し、サイトの API_URL に設定すると連動
  - サイト → シート：予約登録（料金・残席はサーバー側で再計算、同時予約はロックで排他）
  - シート → サイト：ツアー・受付中の出発日・残席（空席カレンダーに表示）
  - シート → Googleカレンダー：出発日ごとの終日予定（予約人数・残席・予約者一覧、催行状況で色分け）。予約時と毎時に同期
- メニュー［サントラベル］：選択した予約の入金済み・確定、キャンセル、カレンダー同期
- サイトからの予約はすべて「仮予約」で登録し、入金確認後に担当者が「確定」にする（カード決済連携は未実装）
- 個人情報を含むため、スプレッドシートの共有は担当者のみに限定する

## 7. 確認が必要なこと
- 所属団体（JATA／ANTA等）の有無
- 掲載ツアーの実際の日程・料金・取消料（デモの値は見本）
- 追加した現地発ツアー（広蔵市場・韓屋の家庭料理・北村さんぽ・陶芸・釜山）とエジプトツアーの実際の内容
- LINE・カカオトーク・X・FacebookのURL
- 実在スタッフの写真
- GitHub リポジトリ名と公開先
