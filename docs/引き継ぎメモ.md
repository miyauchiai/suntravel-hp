## 3. つながり方

- **しおり →（販売中）→ 申込フォーム**：しおりの「基本情報・表紙」で「販売中」にチェックしたツアーのうち、アーカイブしておらず、出発日が今日以降（または未定）のものが、申込フォームの「お申込みのツアー」に出る（Code.gs の `?action=formTours`。最大5分遅れ）
- **しおり →（販売中）→ 予約管理シート**：同じツアーが「ツアー」「出発日」シートに自動で取り込まれる（Code.gs の syncShiori。HPが開かれたとき5分おき／メニュー［サントラベル］→［しおりから取り込む］ですぐ）
  - しおりで上書きする列：ツアー名・サブタイトル・エリア・カテゴリ・日数・料金・含まれるもの・バッジ・画像・公開・しおりID
  - シートで管理する列：定員・1名1室追加・燃油・最少催行人員・評価（最初に作るときだけ初期値）
  - 出発日の受付は、しおりの「販売中」に合わせて「受付中／停止」を切り替える
- **しおり →（HPにも載せる）→ HP**：「HPにも載せる」にチェックすると、シートの「公開」が「公開」になり tours.html のツアー一覧に出る。予約ボタンは HP と同じ場所の `form/?tour=（しおりのID）` を開き（Code.gs の FORM_URL＝相対パス `form/`）、そのツアーを選んだ状態で申込フォームが始まる
- **申込フォーム → 予約管理シート**：送信内容は「フォーム受付」シート（受付番号 SF…）、パスポートは「本人確認書類」シート、写真はドライブ「本人確認書類（写真）」フォルダ
  - あわせて**ツアーごとのスプレッドシート**にも同じ内容を入れる：ドライブ「サントラベル 予約管理 / ツアー別申込」に、しおりのツアー1つにつき1ファイル（「申込_出発日_ツアー名」、シート「申込」「参加者」）。ツアー外の申込は「申込_その他（ツアー外・ご相談）」。最初の申込で自動作成し、ファイルIDは Apps Script の［スクリプト プロパティ］`TOURBOOK_T_（しおりID）` に記録。全体の一覧「フォーム受付」の「ツアー別ファイル」列にリンク
- **ビザ申請フォーム → 予約管理シート**：「ビザ申込」シート（受付番号 VS…）＋「本人確認書類」シート
- **身分証リーダーの保存先への転送**（任意・現在オフ）：Apps Script の［スクリプト プロパティ］に IDREADER_URL と IDREADER_TOKEN を登録すると、フォームのパスポートを「免許証一覧」の「パスポート」シートにも保存する。合言葉はフォームのページには書かない（lookup で氏名・旅券番号を引けてしまうため）

## 4. 申込フォームの中身（form フォルダ）

- index.html：海外旅行申込フォーム（項目は旧Googleフォーム「海外旅行申込フォーム」に準拠：メール、サロン会員、出発日・帰国日、氏名（漢字・ローマ字）、生年月日、電話、郵便番号・住所、パスポート番号・有効期限・写真、緊急連絡先、海外旅行保険、食物アレルギー、無料両替、その他連絡事項）
- visa.html：ビザ申請フォーム（韓国 C-3-9／C-3-4／C-4／D-2・D-4、米国 B-1／B-2、中国、e-Arrival Card）
- forms/pp.js・forms/forms.css：両フォーム共通のパスポート欄（お持ちの方は写真から自動入力、申請中の方は手入力。写真の変更・削除可）
- idreader/：パスポートの読み取りエンジン（身分証リーダーと同じ。小さい写真は拡大して読み、下の2行が読めないときは券面の印字から読む）
